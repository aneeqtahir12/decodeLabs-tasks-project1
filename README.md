# Data Science Project 1 - Decodelabs Tasks

This repository contains my Data Science Project 1 completed as part of the Decodelabs internship tasks.

## Project Overview

This project involves data analysis and basic machine learning using Python. The workflow includes data loading, cleaning, exploratory data analysis, and applying a simple machine learning model.

## Tasks Completed

### Task 1: Data Loading and Understanding

* Loaded dataset using Pandas (read_csv)
* Viewed dataset using head()
* Checked dataset structure using info() and shape

### Task 2: Data Cleaning

* Checked missing values using isnull().sum()
* Checked duplicate values using duplicated()
* Prepared dataset for analysis

### Task 3: Exploratory Data Analysis

* Generated statistical summary using describe()
* Used visualization libraries such as Matplotlib and Seaborn
* Explored patterns and relationships in data

### Task 4: Data Preprocessing

* Applied feature scaling using StandardScaler
* Prepared data for machine learning model

### Task 5: Machine Learning Model

* Split data using train_test_split
* Applied Logistic Regression model
* Trained model on dataset
